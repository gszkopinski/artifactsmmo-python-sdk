# Instructions

Peux-tu contrôler pour chaque endpoint de l'API (https://api.artifactsmmo.com/docs/#/ ), si le SDK l'implémente correctement, que les models sont correctes et que des tests (avec mock) existent. Fait endpoint par endpoint avec à chaque fois un commit par endpoint modifié.
Pour moquer les tests, je préfère que tu utilises pytest-mock. N'utilise pas unittest pour les tests.
Sers toi du fichier @/AGENTS.md comme référence.
Si tu vois qu'il manque des information qui aurait pu t'aider dans ce fichier après tes implémentations, n'hésites pas à le compléter.
Si tu as des questions sur l'implémentation actuelle, n'hésites pas.
Fait un plan d'abord, valide avec moi les actions et tu pourras ensuite les appliquer.
